## 异常处置

| 情况 | 处置 |
|---|---|
| 某 run 死于 git/pathspec 类框架病 | 标记"框架病死亡"，该 run 不计入指标（脚本已带此告警），补跑一次同条件 |
| 网关/模型侧维护窗口 | 暂停，窗口过后继续；受影响的 run 标记后补跑 |
| G 的视图没出现/结构不对 | 回 Step 4 冒烟排查，**不要带着坏注入跑正式批** |
| 想临时改图或改 skill | 禁止。改了就整批作废——想试的变化记下来，跑完这批再说 |
