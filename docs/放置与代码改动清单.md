## B. harness 代码改动（全部三处）

### B-1【必修】git 分支 slug 修复

**定位**：在编排层 grep 分支名构造点——`grep -rn "checkout" src/ .opencode/`，以及 `grep -rn "branch" src/ | grep -i "create\|new\|format\|slug"`。轨迹证据：分支名 `h1-Plan1-特征扩展-超参调优-验证集阈值校准-` 尾部多连字符且分支不存在。

**补丁模式**（应用到分支名构造处）：

```python
import re, subprocess

def slugify_branch(node_id: str, title: str) -> str:
    """分支名唯一生成口——create/checkout/删除全部经此函数，禁止第二处拼名。"""
    s = f"{node_id}-{title}".lower()
    s = re.sub(r"[^a-z0-9一-鿿]+", "-", s)   # 保留 CJK，其余转 -
    s = re.sub(r"-{2,}", "-", s).strip("-_.") # 折叠并 strip 首尾部
    return s[:48].strip("-_.")                # 截断后再 strip 一次

def ensure_branch(repo: str, name: str, base: str = "master") -> None:
    """建分支后立即验证存在；失败即抛，不许静默吞掉。"""
    if not subprocess.run(["git", "-C", repo, "branch", "--list", name],
                          capture_output=True, text=True).stdout.strip():
        subprocess.run(["git", "-C", repo, "checkout", "-b", name, base], check=True)
    # checkout 前校验（防 create/checkout 路径不一致）
    subprocess.run(["git", "-C", repo, "rev-parse", "--verify", name], check=True)
```

**验证**：修好后用同一 tbox 目标跑 `max_trials=3`，trial 不再死于 pathspec 错误，ledger 节点能走到真实结局。

